# Whiteboard

**NOTE**: This was 100% vibe-coded, so use at your own risk.
Check the source code yourself, it all lives in [main.jsx](https://github.com/stuartmaxwell/ha-addons/blob/05d9818d935f405d3b6a0b76c6c4a33dc25e5c06/build/whiteboard/src/main.jsx)
and is only 70-odd lines of actual code, with lots of comments.

A shared [Excalidraw](https://excalidraw.com) whiteboard in your Home
Assistant sidebar.

- Fully self-hosted: Excalidraw is bundled into the add-on, no internet
  access or CDN required.
- One shared board: the scene is saved on the server, so every device
  sees the same drawing.
- Autosaves as you draw.
